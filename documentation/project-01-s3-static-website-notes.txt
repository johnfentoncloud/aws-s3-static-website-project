Lessons Learned
- S3 bucket names must be globally unique
- Static website hosting must be enabled manually
- Public access settings and bucket policies are separate
- Bucket policies control object access
- Block Public Access settings can override bucket policies
- AWS CLI requires configured credentials
- CLI commands must run from the correct working directory
- JSON policies control AWS permissions
- CloudFormation creates infrastructure from templates
- index.html acts as the homepage
- error.html displays when pages are missing
- IAM users are safer than using the root account
- MFA adds important account security
